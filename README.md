# Boda Historia

Sitio de boda que cuenta la historia de la pareja con scroll. Esta versión es una
**demo con contenido de ejemplo**: los nombres, fechas, lugares y textos son ficticios.

- Todo el contenido se edita en `lib/content.ts`.
- Las fotos van en `public/fotos/` y se enlazan con `src` en cada foto.
- Cada push a `main` publica en GitHub Pages.

```bash
npm install
npm run dev
```
